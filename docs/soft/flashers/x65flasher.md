# x65flasher

**Домашняя страница:** [http://chaos.allsiemens.com/software.html](https://web.archive.org/web/20130813164842/http://chaos.allsiemens.com/software.html) (web archive)<br/>
**Автор:** Chaos

Флешер для телефонов 65-75-й серии + мидлет для поиска boot-ключей.

- Чтение и запись flash-памяти телефона
- Бэкап и восстановление как всего fullflash, так и отдельных частей
  (файловой системы, прошивки, EEPROM)
- Просмотр карты flash-памяти
- Работа на скорости от 57600 до 1600000 бит/с
- Генерация лоадеров для V_Klay
