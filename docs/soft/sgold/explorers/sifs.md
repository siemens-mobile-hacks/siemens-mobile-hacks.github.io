# SIFS

**Автор:** Andreas Ziemer<br/>
**Платформы:** x65/x75 (SGOLD)

SIFS — файловый плагин Total Commander для доступа к FlexMemory телефонов
Siemens через последовательный порт и OBEX. Он позволяет просматривать каталоги,
копировать, перемещать, переименовывать и удалять файлы непосредственно из Total
Commander.

Сохранённая сборка основана на SIFS 1.1 и модифицирована для работы с Siemens
x65. Требуется Total Commander 5.51 или новее.
