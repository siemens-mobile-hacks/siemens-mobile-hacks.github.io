# vSOFS

**Домашняя страница:** [http://www.vnavigator.com.ru/](https://web.archive.org/web/20060204214147/http://www.vnavigator.com.ru/) (web archive)<br/>
**Автор:** VNavigator Soft<br/>
**Платформы:** x35/x45/x55 (EGOLD), x65/x75 (SGOLD)

Плагин файловой системы для Total Commander. Поддерживает телефоны Siemens
x55, x65 и x75 и позволяет использовать для работы с файлами все обычные
возможности Total Commander.

Плагин копирует, перемещает и удаляет файлы и папки, создаёт каталоги, сохраняет
даты и атрибуты файлов и принимает команды `CD`, `MD`, `RD` и `DEL` из командной
строки. В диалоге настроек доступны информация о телефоне и AT-терминал.

Встроенный AT Enabler подключает телефоны x65–x75 через нефирменные кабели, а
функция OD 2 открывает их скрытые диски. Начиная с версии 1.7 через BFB Layer
поддерживаются C55, ME45 и SL45.
