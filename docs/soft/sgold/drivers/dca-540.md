# Siemens DCA-140/DCA-540 Driver

**Автор:** Siemens AG; модификации — artold, SARS<br/>
**Платформы:** x10/x25 (HIGOLD), x35/x45/x55 (EGOLD), x65/x75 (SGOLD), ODM, BREW

Драйверы предназначены для USB-кабелей Siemens DCA-140 и DCA-540. Официальный
комплект 1.05 содержит INF и системные файлы для Windows 98/ME и Windows
2000/XP, а также утилиту удаления драйвера.

Комплект artold добавляет поддержку DCA-140 в Windows XP x64 и Windows 7 x64.
Передача файлов между компьютером и телефоном работает, в том числе через
плагин SOFS для Total Commander; работа в качестве модема автором сборки не
подтверждена.

Модификация SARS позволяет установить DCA-140 в 32- и 64-разрядной Windows 10
как `Modem Interface`. Драйвер работает с файловыми менеджерами, включая SiMoCo
и плагины VSFE для Total Commander и FAR Manager.
