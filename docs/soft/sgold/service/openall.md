# OpenAll

**Платформы:** x35/x45/x55 (EGOLD), x65/x75 (SGOLD)

OpenAll получает данные телефона Siemens x55/x65 и рассчитывает сервисные ключи, после чего открывает чтение и запись блоков EEPROM.
Для x55 поддерживаются кабель, Bluetooth и IrDA, для x65 — кабель на скорости 57600 бод.
