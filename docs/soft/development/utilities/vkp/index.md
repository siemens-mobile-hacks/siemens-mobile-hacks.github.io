# VKP

Утилиты для создания, анализа и преобразования патчей VKP.

## Программы

- **[FFPatch](./ffpatch.md)**<br/>
  Программа для сравнения образов FullFlash и работы с патчами VKP.
- **[Fullflash Comparer](./fullflash-comparer.md)**<br/>
  Создание патча VKP по различиям между исходным и изменённым FullFlash.
- **[Hex2VKP](./hex2vkp.md)**<br/>
  Конвертер Intel HEX в формат патчей VKP для V_KLay.
- **[SLFC](./slfc.md)**<br/>
  Консольная программа для сравнения образов FullFlash и создания VKP-патчей.
- **[VkpResolver](./vkp-resolver.md)**<br/>
  Размещение графических VKP-патчей в свободной области прошивки без пересечения адресов.
- **[VkpTracer](./vkp-tracer.md)**<br/>
  Перенос выбранного диапазона адресов в VKP-патче с исправлением ссылок.
