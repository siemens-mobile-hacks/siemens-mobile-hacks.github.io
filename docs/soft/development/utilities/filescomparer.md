# FilesComparer

**Домашняя страница:** [http://vi-soft.com.ua/](https://web.archive.org/web/20130813164842/http://vi-soft.com.ua/) (web archive)<br/>
**Автор:** SaiNT

Для DOS. Сравниватель файлов/флешей может сравнивать не только равные по размеру файлы, но и неравные, а также выполнять сравнение с начального по конечный адреса, которые задает сам пользователь. Параметры можно задавать из командной строки. Возможность выравнивания результатов по байтам. Под DOS & Windows.
