# Hex2VKP

**Домашняя страница:** [http://vi-soft.com.ua/](https://web.archive.org/web/20130813164842/http://vi-soft.com.ua/) (web archive)<br/>
**Автор:** Redkin

Для Windows, с консольным интерфейсом. Hex2VKP — конвертер из Intel HEX
формата в формат программы V_Klay — .VKP.

HEX (.H86) — это формат от фирмы Intel, специально предназначенный для
загрузки данных в микроконтроллеры. Многие компиляторы для C166 (в том числе
Keil и Tasking C) умеют выдавать результаты в этом формате. Таким образом,
заливка патчей в телефон становится проще. Все, что вам остается сделать
после компиляции патча, — это сконвертировать его данным тулом в формат .VKP и
залить в телефон программой V_KLay.
