# Smelter

**Домашняя страница:** [https://avkiev.kiev.ua/Siemens/Smelter/Smelter_ru.htm](https://web.archive.org/web/20130401035858/https://avkiev.kiev.ua/Siemens/Smelter/Smelter_ru.htm) (web archive)<br/>
**Автор:** avkiev

Эта программа предназначена для исследования фуллфлеша телефона. Она
вытаскивает из фф информацию о еепромах, ленгпаке, меню, картинках, мелодиях,
файлах и многом другом, после чего показывает их в удобном виде. Программа
заточена под 55-ю серию, но, по идее, должна грамотно работать и с
фуллфлешами других телефонов. Изначально предназначена для флешекопателей, но
может быть полезна и неискушенным пользователям.

Возможности:

- Вывод найденной в фф информации;
- Просмотр, загрузка и выгрузка блоков EEPROM, расшифровка содержимого
  отдельных блоков, создание резервных копий и определение IMEI;
- Просмотр и редактирование ленгпака, загрузка и сохранение всего ленгпака или
  его области;
- Исследование системы меню и поиск точек входа элементов;
- Просмотр и выгрузка картинок из фф;
- Просмотр, прослушивание, загрузка и выгрузка мелодий;
- Просмотр содержимого флекс-мемори и выгрузка файлов;
- Графический просмотр фф по блокам;
- Просмотр адресной книги x45–x65;
- Поиск байт с маской и выравниванием, поиск текста;
- Создание VKP-патча из изменений фф и запуск V_Klay;
- Сохранение списков в текстовый формат и IDC-файлы для IDA, поиск по спискам
  и интеграция с WinHex или HexWorkshop;
- Мультиязычный интерфейс;
- Просмотр фф, стандартный калькулятор Windows и отдельный Calc166;
- Поиск стандартных функций по заданным в ini-файле сигнатурам;
- Генерация стандартных патчей по заданным в ini-файле сигнатурам;
- Нахождение бут-ключей и создание лоадера для V_Klay;
- Брут-форсовый поиск PhoneID;
- Поиск мастер-кодов для разлочки;
- Включение дополнительных менюшек в WinSwup;
- Создание сертификатов и подписывание мидлетов без Java;
- Дизарм, МикроАсм, работа с библиотекой функций и скриптами;
- Проверка и стрипание эльфов.

Для корректной работы программы необходимы OCX-компоненты из комплекта OCX
Control, размещённого в дополнительных файлах.
