# vmo2wav

**Домашняя страница:** [http://chaos.allsiemens.com/software.html](https://web.archive.org/web/20130813164842/http://chaos.allsiemens.com/software.html) (web archive)<br/>
**Автор:** Chaos

Программа-конвертер файлов диктофонных записей (VMO) в формат WAV. Запускается
из командной строки (MS-DOS prompt, FAR, Windows Commander).

По умолчанию программа нормализует (выравнивает) уровень сигнала. Эту функцию
можно отключить, запуская vmo2wav с параметром `-n`.
