# Аудио

Конвертеры и редакторы мелодий, рингтонов и звуковых файлов.

## Программы

- **[Create Ringtone](./create-ringtone.md)**<br/>
  Создание рингтонов из аудиофайлов и CD-треков, а также подготовка обоев для мобильных телефонов.
- **[MA-1 SMF to SMAF Converter](./smf-to-smaf-converter.md)**<br/>
  Преобразование MIDI-файлов SMF в мелодии SMAF/MA-1 формата MMF.
- **[MIDIConverter](./midi-converter.md)**<br/>
  Создание MIDI-мелодий для Siemens S/C25 и M/C/S35 по текстовой записи нот.
- **[MP3Siem](./mp3siem.md)**<br/>
  Подготовка MP3-файлов для воспроизведения на телефонах Siemens C55/M55/S55/SX1 и 65-й серии.
- **[Ringtone Editor](./ringtone-editor.md)**<br/>
  Редактирование монофонических мелодий Siemens C/M35 и Nokia Standard.
- **[Universal Ringtone Converter](./universal-ringtone-converter.md)**<br/>
  Преобразование MIDI и текстовых мелодий телефонов Siemens, Nokia и Ericsson с редактором и проигрывателем.
- **[vmo2wav](./vmo2wav.md)**<br/>
  Конвертер диктофонных записей Siemens SL45 из VMO в WAV.
- **[WAV/AMR Converter](./wav-amr-converter.md)**<br/>
  Преобразование звука между WAV и AMR для использования в мобильных телефонах.
