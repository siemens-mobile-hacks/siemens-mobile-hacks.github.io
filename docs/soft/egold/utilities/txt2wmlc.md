# TXT2WMLC

**Автор:** CheSer software<br/>
**Платформы:** x35/x45/x55 (EGOLD)

TXT2WMLC преобразует текстовый файл в одну или несколько страниц WMLC для просмотра в WAP-браузере телефонов Siemens 45-й серии.
Полученные файлы можно открыть из Card-Explorer или по локальному URL `file:a:\путь\имя.wmlc`.

Программа выполнена в виде сценария Windows Script Host и запускается из командной строки.
