# NV Editor

**Автор:** Krzysztof Kędzior<br/>
**Платформы:** BREW

![NV Editor: скриншот 1](./nv-editor/img/nv-editor.jpg)

NV Editor позволяет редактировать содержимое NV Items и сохранять результат в
файлы или непосредственно в телефон. Значения показываются в читаемом виде — в
десятичном и шестнадцатеричном представлении.

Возможности:

- Подключение к телефону через QPST Server;
- Чтение NV Items из телефона и запись обратно;
- Загрузка и сохранение наборов в форматах BRT и CNV;
- Создание CSV-списков NV Items;
- Отправка SPC-кода телефону;
- Выбор и сортировка NV Items по имени, ID, размеру и типу данных;
- Добавление описаний новых NV Items и структур данных через DEF-файлы.

Для работы необходимо установить QPST Server. В комплекте находится подробное
руководство пользователя.
