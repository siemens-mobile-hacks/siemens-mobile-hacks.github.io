# SWriteMapR65

**Author:** Siemens

Siemens service utility for writing standard and delta MAP files to the
EEPROM of x75 series phones. Communicates with the phone via the COM port in
BFB Mode; Factory Mode and Developer Mode are supported.

The archive includes the NI LabWindows/CVI runtime environment required to run
the program.
