# Siemens EEPROM Tool

**Author:** Skylord

This program is intended for working with the EEPROM of Siemens mobile phones via
Service Mode. It allows you to read and save EEPROM blocks either all at once or
individually. You can also save them to disk all together, separately, or however
you like — in binary and text hexadecimal
format. And in general — it does a whole lot more. There are currently no analogs
with similar functionality. ;-)

Program features:

- Read all or selected blocks from the phone, as well as blocks with specified
  numbers and number ranges.
- Write all or only selected blocks and delete individual blocks directly
  from the phone.
- Transfer blocks between the user data list and the phone EEPROM
  list.
- Compare all or selected blocks in two lists.
- Load and save blocks in EEP, BIN, and text HEX formats.
- Read standard and delta InitMap mappings, as well as Freia MAP files.
- Sequentially load multiple files, replacing duplicate blocks with data from the last file.
- Work with EELITE and EEFULL on x65 phones.
- Retrieve phone information available via Service Mode and the free
  space in EEPROM.
- Display block descriptions from `eeprom.dsc` taking the hardware platform version into account.
- Create `eeprom.dsc` from InitMap mappings using the included GetMapDesc
  program.
- Launch external programs to edit the selected block and then load the result back.
- Support for up to 16 COM ports and entering Service Mode on a powered-on phone using
  PreCheck.

To use it, you need a standard Siemens cable with external power. COM or USB
— it does not matter, as long as the cable chips are not powered by the phone.

Do not use this program if you do not know what EEPROM is and what it is
for. It can quickly and painlessly kill your phone, and bringing it back to life
is your problem.
