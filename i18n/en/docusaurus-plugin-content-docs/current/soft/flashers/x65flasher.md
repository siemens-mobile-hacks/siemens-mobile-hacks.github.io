# x65flasher

**Homepage:** [http://chaos.allsiemens.com/software.html](https://web.archive.org/web/20130813164842/http://chaos.allsiemens.com/software.html) (web archive)<br/>
**Author:** Chaos

Flasher for 65-75 series phones + a midlet for finding boot keys.

- Reading and writing the phone's flash memory
- Backup and restore of both the entire fullflash and individual parts
  (file system, firmware, EEPROM)
- Viewing the flash memory map
- Operation at speeds from 57600 to 1600000 bit/s
- Generating loaders for V_Klay
