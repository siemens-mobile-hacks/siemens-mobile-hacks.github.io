# SMS Translit

**Author:** Triguk_VV

SMS Translit lets you compose messages in Cyrillic and use Russian
T9, and before sending it replaces Russian letters with Latin ones. This increases the limit
for a single SMS from 70 Unicode characters to 160 characters of the standard alphabet.

The program shows the number of message parts before and after transliteration,
automatically and manually saves SMS messages. In version 0.04b, the replacement table is stored in
an editable `translit.ini` file; the package also includes an alternative
Nitrogen table.
