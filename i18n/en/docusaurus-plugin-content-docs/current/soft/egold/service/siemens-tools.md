# Siemens Tools

**Platforms:** x35/x45/x55 (EGOLD)

The package includes Siemens EEPROM Tool and Siemens Sensors Tool 1.3. EEPROM Tool reads and writes the EELITE and EEFULL areas either in full or
as individual blocks, and Sensors Tool works with sensor calibration data in EEPROM block 67.

The programs use the Bfb95EG library and work with Siemens 35/45 series phones. The archive also includes ready-made versions of block
67 for different models, firmware versions, and batteries.
