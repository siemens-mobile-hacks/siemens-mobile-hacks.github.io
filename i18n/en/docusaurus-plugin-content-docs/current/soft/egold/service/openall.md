# OpenAll

**Platforms:** x35/x45/x55 (EGOLD), x65/x75 (SGOLD)

OpenAll retrieves Siemens x55/x65 phone data and calculates service keys, then unlocks EEPROM block read and write access.
For x55, cable, Bluetooth, and IrDA are supported; for x65, cable at 57600 baud is supported.
