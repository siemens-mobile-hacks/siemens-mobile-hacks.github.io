# Siemens Quick EEPROM Features

**Author:** Skylord<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![Siemens Quick EEPROM Features: screenshot 1](./siemens-quick-eeprom-features/img/siemens-quick-eeprom-features.png)

By writing patched EEPROM blocks via ServiceMode, the program allows you to enable the following features:

- Access the disk of M50, MT50, and C55 phones from a computer.
- Disable the "airplane" check on C45, S45, ME45, S45i, M50, MT50, C55, S55, SL55, and M55.
- Fix the inability to reassign function keys on the C45.
- Activate the Developer Menu on the C55 via a number on the SIM card.
- Add a GSM band selection menu item on phones of the 35th, 45th, 50th, and 55th series.
- Fix block 68 after converting an S45 or ME45 to an S45i.
- Write block 5005, which enables Java on the SL45 or a flashed SL42.

The program automatically detects the features available for the connected phone and saves a backup copy of the EEPROM block to an
EEP file before writing. Operation with a powered-off phone via ServiceMode and with powered-on x55 devices is supported.
