# UniSiemens Professional

**Platforms:** x35/x45/x55 (EGOLD), ODM

![UniSiemens Professional: screenshot 1](./unisiemens/img/unisiemens.png)

A program for reading and writing FullFlash, EEPROM, or a specific flash memory range on Siemens phones.

Supports C30, S40, models from the x35 and x45 families, and when SL4x is selected — A50, M50, and MT50. The package includes loaders for different phone families.
