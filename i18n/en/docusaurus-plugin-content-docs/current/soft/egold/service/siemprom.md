# SiemPROM

**Homepage:** [http://avkiev.siemens-club.ru/Siemens/SiemPROM/SiemPROM.htm](http://avkiev.siemens-club.ru/Siemens/SiemPROM/SiemPROM.htm)<br/>
**Author:** avkiev<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![SiemPROM: screenshot 1](./siemprom/img/siemprom.png)

SiemPROM analyzes FullFlash, extracts information about EEPROM blocks, their offsets and sizes, and displays it to the user. For known
blocks, additional decoding of the contents is available.

The program supports the user T9 dictionary, greeting, groups, WAP bookmarks, notes, alarm clock, x55 engineering menu, SMS list,
Factory Service Profile, user phrases, Bluetooth identification and known devices, Java connection timeout, and other service blocks.

SiemPROM was tested by the author on Siemens phones of the 35, 45, 50, and 55 series. Block descriptions are stored in the external file
`eeprom.dsc`, which can be extended.
