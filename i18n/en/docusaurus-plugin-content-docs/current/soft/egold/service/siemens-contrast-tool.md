# Siemens Contrast Tool

**Author:** Skylord<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![Siemens Contrast Tool: screenshot 1](./siemens-contrast-tool/img/siemens-contrast-tool.png)

This program is intended for adjusting the contrast of Siemens phones. This may
be necessary, for example, after upgrading an S/ME45 to an S45i, when the phone
works but nothing is visible on the screen.

After connecting the cable and switching to Service Mode, you can change the
contrast from 0 to 63 using the slider or by entering a numeric value and
immediately see the result on the display. The `Read contrast` button reads the
current value, and `Write contrast` saves the selected value to the phone.
