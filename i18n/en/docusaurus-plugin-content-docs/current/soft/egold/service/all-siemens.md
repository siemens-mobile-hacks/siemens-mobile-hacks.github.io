# All Siemens Unlocker

**Author:** Nutzo<br/>
**Platforms:** x35/x45/x55 (EGOLD), ODM

![All Siemens Unlocker: screenshot 1](./all-siemens/img/all-siemens.png)

All Siemens Unlocker performs direct phone unlocking, creates a backup MAP and a MAP for unlocking using a LOG file, writes
MAP to the phone, and decrypts EEPROM blocks. The program also reads Flash in KSI and FLS formats, writes firmware, and checks or
fixes CRC in Flash.

This is a standalone predecessor to Freia with its own name and interface.
