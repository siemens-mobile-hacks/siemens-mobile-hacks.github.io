# S45i v4 Activator

**Homepage:** [http://gsmdev.de/index.php?c=viewprojektinfo&id=13](https://web.archive.org/web/20050313185721/http://gsmdev.de/index.php?c=viewprojektinfo&id=13) (web archive)<br/>
**Author:** ACiD[mrp], Cluni<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![S45i v4 Activator: screenshot 1](./s45i-activator/img/s45i-activator.png)

S45i v4 Activator simplifies upgrading Siemens S45 and ME45 phones to S45i v4. The program applies the selected firmware modifications:

- Disable Airplane Check;
- Disable SAT;
- Enable [BFB Mode](https://patches.kibab.com/patches/search.php5?action=search&kw=BFB);
- Enable the Band Selection menu;
- Access FlexMem without a SIM card;
- Fix the temperature issue.

Phones based on the BA chipset are supported.

If the error `failed to load 'gsmdev' from . version may be outdated.` occurs, the DLL package from gsm-multifund.de is required.
