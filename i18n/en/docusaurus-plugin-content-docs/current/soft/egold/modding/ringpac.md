# RingPac

**Author:** Sep.<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![RingPac: screenshot 1](./ringpac/img/ringpac.png)

RingPac analyzes the index of built-in RIT melodies and the FullFlash areas
occupied by them. The program displays index entries, gaps, and free blocks,
extracts individual or all melodies in MID, WAV, and SRT formats.

Melodies can be repacked into the blocks described in `free.ini` to create a
VKP patch. Identical files are saved once with multiple references from RIT. This
makes it possible to use larger melodies at the expense of others and free up space for
a Flex disk or PicPac graphics. The remaining space in blocks can be filled with
`0xFF` bytes if needed; the finished patch can be opened directly in V_KLay.
