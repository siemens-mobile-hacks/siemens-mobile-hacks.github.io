# Siemens C45ffimager

**Author:** Krystallin<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![Siemens C45ffimager: screenshot 1](./c45ffimager/img/c45ffimager.png)

This program is intended for changing graphics in the Siemens C45 and other phones where
images are encoded according to the same principle. It encodes an image according to the
C45 rules and, if it can be compressed to the size of the original, inserts it into the FullFlash in place of
the old one.

Not only replacement but also adding images at the specified
offset and parameters is supported. Information about the images is stored in a separate list file; the
archive includes, as an example, a list for the Siemens C45 with firmware 50.
