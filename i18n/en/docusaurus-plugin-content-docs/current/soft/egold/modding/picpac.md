# PicPac

**Author:** Sep.<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![PicPac: screenshot 1](./picpac/img/picpac.png)

The idea behind the program is as follows: the phone has a memory area where images are stored, and an index of these images with their addresses — PIT.
Usually, when replacing an image, it is written to the old location or to a free area that was found, and the previous location is lost. If you describe all the
space occupied by graphics and rewrite the images together with the index each time they are changed, a large image can be placed by deleting
or reducing another one.

PicPac analyzes FullFlash and shows the space occupied by images, extracts graphics without changing the original palette, places
the specified images into the given blocks, and if successful creates a VKP patch. Uncompressed and compressed 1, 2, 8, 12, and 16-bit formats are supported,
multiple PITs, duplicate and free block search, deletion of unnecessary images, and launching the resulting patch in V_KLay.

The package includes settings for C55, CF62, M55, MC60, and S55. Using its own INI file, the program can work with another
phone for which the locations of the PIT and the graphics area are known.
