# SLIK Graphical Menu Builder

**Homepage:** [http://www.sama.ru/~kovalev/](https://web.archive.org/web/20031018002518/http://www.sama.ru/~kovalev/) (web archive)<br/>
**Author:** Sergey Kovalyov<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![SLIK Graphical Menu Builder: screenshot 1](./slik-graphical-menu/img/slik-graphical-menu.png)

The program lets you create a custom graphical menu for Siemens SL42,
SL45, and SL45i with firmware version 56. The result is a patch in VKP format
for uploading to the phone using the V_KLay program. The Graphical Menu patch
by RizaPN is used as the prototype.

Menu items and icons are placed on the display layout by drag and drop. You can
edit labels, their position and font, choose the highlight style and skin,
assign menu invocation to the right arrow or the right soft key. Images can be
embedded directly into the VKP patch or saved separately.

The list of items and their addresses is stored in the editable `items.xml`. The package
also includes a collection of black-and-white icons and skins for the editor.
