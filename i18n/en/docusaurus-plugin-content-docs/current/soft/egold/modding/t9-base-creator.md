# Siemens X55 T9 Base Creator

**Author:** F.U.H.<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![Siemens X55 T9 Base Creator: screenshot 1](./t9-base-creator/img/t9-base-creator.png)

This program is intended for creating a T9 database from existing languages. You can
include only the required dictionaries in the database and get a ready BIN for writing to the phone via
V_KLay. The result file name contains the offset corresponding to the selected model.

The package includes 22 language databases from the A55. The author tested the program on the Siemens
S55; the T9 area address for other models must be determined in advance,
for example using Smelter.
