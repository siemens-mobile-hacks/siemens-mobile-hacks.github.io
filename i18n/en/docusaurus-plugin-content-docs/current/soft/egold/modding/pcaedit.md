# PCAEdit

**Author:** Sen'ja<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![PCAEdit: screenshot 1](./pcaedit/img/pcaedit.png)

This program is intended for editing the `graphcach.pca` file, which stores the
phone power-on and power-off animations. The first eight images correspond to
power-on, the next eight to power-off. You can replace them with your own
images and save the modified PCA file.

The size of the inserted images must match the original.
