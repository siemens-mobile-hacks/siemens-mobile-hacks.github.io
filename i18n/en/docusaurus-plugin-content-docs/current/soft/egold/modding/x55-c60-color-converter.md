# x55/C60 Color Converter

**Platforms:** x35/x45/x55 (EGOLD)

![x55/C60 Color Converter: screenshot 1](./x55-c60-color-converter/img/x55-c60-color-converter.png)

The program converts a COL color scheme file created by Color Scheme Editor for Siemens x55 into a BIN block for writing to the EEPROM of the Siemens
C60. The x55 and C60 formats differ in the purpose of some lines, so the shades on the editor screen and on the phone may not match.
