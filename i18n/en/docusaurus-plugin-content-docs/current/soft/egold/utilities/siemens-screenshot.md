# Siemens Screenshot

**Author:** ACiD[mrp]<br/>
**Platforms:** x35/x45/x55 (EGOLD)

![Siemens Screenshot: screenshot 1](./siemens-screenshot/img/siemens-screenshot.png)

Siemens Screenshot captures an image from the phone display via BFB. Operation has been
verified with ME45i, S55, M55, and SL55; the program is also intended for C45, S45, ME45,
M50, MT50, C55, A60, and C60. Both monochrome and color displays are supported, including
the 4096-color palette.

Some firmware versions require a patch to access BFB. The archive includes a description
of the operating mode, version history, and ready-made patches for several models.
