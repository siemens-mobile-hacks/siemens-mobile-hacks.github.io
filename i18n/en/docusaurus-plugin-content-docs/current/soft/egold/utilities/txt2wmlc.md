# TXT2WMLC

**Author:** CheSer software<br/>
**Platforms:** x35/x45/x55 (EGOLD)

TXT2WMLC converts a text file into one or more WMLC pages for viewing in the WAP browser of Siemens 45-series phones.
The resulting files can be opened from Card-Explorer or via the local URL `file:a:\путь\имя.wmlc`.

The program is implemented as a Windows Script Host script and is launched from the command line.
