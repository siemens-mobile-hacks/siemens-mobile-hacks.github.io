# EFS Explorer Lite

**Author:** BenQ Mobile<br/>
**Platforms:** BREW

EFS Explorer Lite lets you browse the contents of the Embedded File System
(EFS) on Qualcomm-based phones.

The program copies and moves files between the Windows file system and EFS,
creates and deletes directories, and deletes, views, and edits files.
UTF-8 is supported in file and directory names.

The program was developed by Karolina Borowik and Marcin Was from the BenQ
Mobile PHE R&D SWM DL WRO 3GT division.
