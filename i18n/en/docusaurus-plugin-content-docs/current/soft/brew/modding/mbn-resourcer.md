# MBN Resourcer

**Author:** Viper BJK<br/>
**Platforms:** BREW

![MBN Resourcer: screenshot 1](./mbn-resourcer/img/mbn-resourcer.png)

MBN Resourcer, also called AMSS Analyser, is intended for analyzing
`AMSS.MBN` and QAPP files of phones on the BREW platform, including Siemens SXG75 and
BenQ-Siemens EF81, E61, and other models.

The program extracts resource and application tables, MagicTable, certificates, and
strings, searches for references, and saves the found data to the selected directory. Version
1.51 additionally recognizes the Qualcomm diagnostic command table.

.NET Framework 2.0 is required to run it.
