# CGSN Debugger

**Home page:** [http://alexsid.antex.ru/index.php?main=techinfo.php](https://web.archive.org/web/20050901015815/http://alexsid.antex.ru/index.php?main=techinfo.php) (web archive)<br/>
**Author:** KonstanT

A debugger for working with the internal RAM, ROM, and Flash memory of Siemens phones
on the EGOLD platform through the corresponding version of the AT+CGSN patch.

- Read a memory region to a file;
- Write to and fill memory;
- Search for data within a segment;
- Monitor a selected memory region;
- Call a procedure at a specified address with register values set.
