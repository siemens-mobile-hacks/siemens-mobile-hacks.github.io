# LayoutMe

**Homepage:** [http://avkiev.kiev.ua/Siemens/LayoutMe/LayoutMe.htm](https://web.archive.org/web/20130401035858/http://avkiev.kiev.ua/Siemens/LayoutMe/LayoutMe.htm) (web archive)<br/>
**Author:** avkiev

This program is intended for editing keyboard layouts on Siemens phones. The program lets you get rid of annoying gibberish at the end of character sequences, localize layouts for Russian, and also create exotic layouts such as АБЦ2ABC and similar ones.

Features:

- Edit the layout in a fullflash;
- Import and export the layout to a standalone `*.lay` file;
- Save the modified fullflash or a VKP patch;
- Integration with V_Klay;
- WAP layout support;
- Russian input support in the built-in mail client using KOI-8;
- Track the number of used and available characters;
- Automatic detection of the model and firmware version.

Supported firmware versions: C45_3803, C45_5001, ME45_2803, ME45_3003,
S45i_0403, SL45_5601, 2118_3108, A50_1091, A50_1105, A50_1191, A50_1201,
MT50_1791, M50_1791, M50_1991, A55_0901, C55_2491, M55_1002, M55_1091,
M55_1191, M55_1192, M55_9191, S55_2091, S55_9191, SL55_1491, SL55_1691,
A52_0701, A60_1095, C60_2391, C60_2591, C60_2691, C60_2791, MC60_1095,
CF62_0791, and CF62_1191.
