# FilesComparer

**Homepage:** [http://vi-soft.com.ua/](https://web.archive.org/web/20130813164842/http://vi-soft.com.ua/) (web archive)<br/>
**Author:** SaiNT

For DOS. The file/flash comparer can compare not only files of equal size, but also files of different sizes, and can also compare within a user-defined address range from start to end. Parameters can be specified from the command line. Supports byte alignment of results. For DOS & Windows.
