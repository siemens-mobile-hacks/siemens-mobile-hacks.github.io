# Hex2VKP

**Homepage:** [http://vi-soft.com.ua/](https://web.archive.org/web/20130813164842/http://vi-soft.com.ua/) (web archive)<br/>
**Author:** Redkin

For Windows, with a console interface. Hex2VKP is a converter from Intel HEX
format to the V_Klay program format — .VKP.

HEX (.H86) is a format from Intel specifically designed for
loading data into microcontrollers. Many compilers for C166 (including
Keil and Tasking C) can output results in this format. This makes
uploading patches to the phone easier. All that remains after compiling
the patch is to convert it with this tool to the .VKP format and
upload it to the phone using V_KLay.
