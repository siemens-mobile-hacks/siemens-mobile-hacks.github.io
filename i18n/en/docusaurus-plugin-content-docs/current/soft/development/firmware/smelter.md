# Smelter

**Homepage:** [https://avkiev.kiev.ua/Siemens/Smelter/Smelter_ru.htm](https://web.archive.org/web/20130401035858/https://avkiev.kiev.ua/Siemens/Smelter/Smelter_ru.htm) (web archive)<br/>
**Author:** avkiev

This program is intended for analyzing a phone fullflash. It extracts
information about EEPROMs, the language pack, menus, pictures, melodies,
files, and much more from the fullflash, and then displays them in a
convenient form. The program is optimized for the 55 series, but in theory it
should also work properly with fullflashes from other phones. It was originally
intended for flash researchers, but may also be useful for inexperienced users.

Features:

- Display information found in the fullflash;
- View, load, and unload EEPROM blocks, decode the contents of individual
  blocks, create backups, and determine the IMEI;
- View and edit the language pack, load and save the entire language pack or
  its area;
- Explore the menu system and search for entry points of elements;
- View and extract pictures from the fullflash;
- View, listen to, load, and extract melodies;
- View the contents of flex memory and extract files;
- Graphical fullflash block view;
- View the x45–x65 phonebook;
- Search for bytes with a mask and alignment, search for text;
- Create a VKP patch from fullflash changes and launch V_Klay;
- Save lists in text format and IDC files for IDA, search within lists,
  and integrate with WinHex or HexWorkshop;
- Multilingual interface;
- Fullflash viewer, standard Windows calculator, and separate Calc166;
- Search for standard functions using signatures specified in the ini file;
- Generate standard patches using signatures specified in the ini file;
- Find boot keys and create a loader for V_Klay;
- Brute-force search for PhoneID;
- Search for master codes for unlocking;
- Enable additional menus in WinSwup;
- Create certificates and sign midlets without Java;
- Disarm, MicroAsm, work with the function library and scripts;
- Check and strip ELF files.

For the program to work correctly, OCX components from the OCX
Control package included in the additional files are required.
