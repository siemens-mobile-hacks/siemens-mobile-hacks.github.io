# C25info

**Platforms:** x10/x25 (HIGOLD)

![C25info: screenshot 1](./c25info/img/c25info.png)

C25info displays information about Siemens C25 and C28 phones: firmware version, IMEI, battery charge, lock status, and network registration status.
The program lets you enable Net Monitor and the full service menu, upload a MIDI melody, and send AT commands to the phone.
