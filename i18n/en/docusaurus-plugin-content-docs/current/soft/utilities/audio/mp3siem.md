# MP3Siem

![MP3Siem: screenshot 1](./mp3siem/img/mp3siem.png)

MP3Siem re-encodes MP3 files through an intermediate WAV at 16 kHz and mono for playback on Siemens C55, M55, S55,
SX1, C65, CX65, M65, and S65. The package includes the LAME encoder and SoX.
