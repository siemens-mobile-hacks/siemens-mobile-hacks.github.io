# Flash Programmer

**Author:** Microcell Ltd<br/>
**Platforms:** ODM

![Flash Programmer: screenshot 1](./flash-programmer/img/flash-programmer.png)

A flasher for the Siemens C62. Loads the main software, language pack, and personalization package onto the phone.

Version 2.83 supports writing GDFS recovery packages. The program requires separate C62 firmware files to work; they are not included in the package.
