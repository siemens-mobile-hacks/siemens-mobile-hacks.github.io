# FAROBEX

**Platforms:** x65/x75 (SGOLD)

A file system plugin for Far Manager that works with Siemens x65,
x70, and x75 phones over OBEX.

Features:

- Copying files and folders, including nested ones, in both directions;
- Moving and deleting files and folders;
- Creating folders;
- Preserving file attributes, date, and time when copying;
- Editing file attributes;
- Viewing IMEI, IMSI, OBEX version, MTU, and free disk space;
- Built-in automatic AT Enabler for connecting via non-original cables.
