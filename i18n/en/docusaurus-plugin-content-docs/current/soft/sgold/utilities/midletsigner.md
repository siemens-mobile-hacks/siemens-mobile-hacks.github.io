# MidletSigner

**Homepage:** [http://chaos.allsiemens.com/software.html](https://web.archive.org/web/20130813164842/http://chaos.allsiemens.com/software.html) (web archive)<br/>
**Author:** Chaos<br/>
**Platforms:** x65/x75 (SGOLD)

So, what is this program for?

You have probably noticed that any midlet that accesses files in the phone's
memory or connects to the internet displays annoying "allow?.." prompts every
time. You can get rid of them by adding a digital signature to the midlet.
Previously, only a developer could do this by contacting a certification center
(which, of course, would want to be paid for it :). Now you can sign
Java midlets yourself.

In addition to getting rid of unnecessary prompts, this also makes it possible
(for developers) to launch a midlet automatically at a specific time or on an
event (for example, when an SMS arrives).

What you need for this:

- JRE version 1.3 or later
- For the 65 series — OpenDisc 2.0 by SiNgle
- For the 75 series — SKEY must be entered on the phone
