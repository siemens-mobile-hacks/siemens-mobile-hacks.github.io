# BenQ-Siemens EL71 ThemeBuilder

**Homepage:** [http://trubinov.ocpi.ru/](https://web.archive.org/web/20070909015533/http://trubinov.ocpi.ru/) (web archive)<br/>
**Forum thread:** [http://e71.ru/forum/20-79-1](http://e71.ru/forum/20-79-1)<br/>
**Author:** Blind007<br/>
**Platforms:** x65/x75 (SGOLD)

The program builds themes for the BenQ-Siemens E71 and EL71. You can add
ringtones, message, power-on, and power-off sounds, animation,
a screensaver, a wallpaper, menu elements, status bars, borders, and other
graphic resources to a theme.

Version 1.0.3.0 adds a phone display preview and
log file support. Opening and editing already built themes is not implemented.
