# BrOoM NetMonitor 2006

**Author:** BrOoM<br/>
**Platforms:** x65/x75 (SGOLD)

![BrOoM NetMonitor 2006: screenshot 1](./broom-netmonitor/img/broom-netmonitor.png)

The program was written to retrieve data from the NetMonitor of Siemens
x65–x75 phones via AT commands, followed by decoding and processing, which
significantly simplifies cellular network monitoring.

It displays the parameters of the current and neighboring cells, the list of BCCH channels, the results of
Network Measurement Results, and the event log. The report can be saved as HTML.
To work with the BenQ-Siemens E71, select S75 in the compatibility settings.
