# EEPROMForm

**Home page:** [http://chaos.allsiemens.com/software.html](https://web.archive.org/web/20130813164842/http://chaos.allsiemens.com/software.html) (web archive)<br/>
**Author:** Phantom<br/>
**Platforms:** x65/x75 (SGOLD)

![EEPROMForm: screenshot 1](./eepromform/img/eepromform-before.gif)

EEPROMForm is intended for formatting and clearing the EELITE and EEFULL areas
in Siemens x65 phones.

Before operations, the program saves backup copies of EEPROM, EELITE, and EEFULL.
It displays the phone model and IMEI, the number of occupied blocks before and after
formatting, the bus level, and the battery voltage. EEPROM operations
are performed in service mode.
